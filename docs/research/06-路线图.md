# 路线图：先完成小说，再扩展交互

以下按依赖与验收门槛排序，不预估未经评估的日期。后续模块是可选扩展，不要求所有小说作者下载游戏引擎或学习脚本。

## 当前开发版 · 0.1

- **已有**：Electron 壳、工作区、会话、章节与资料、保存与快照、作者手工阶段检查、结构卡片、Markdown 导出。
- **已有**：AI 空章生成、续写、整章表达优化；显式参考设定、取消、提案采纳／放弃、旧 hash 拒绝覆盖。
- **已有**：明暗主题、专注模式、命令面板、设计规范与离线展示、unit／Electron E2E、双平台 CI 配置。
- **交付边界**：本轮未运行 GitHub Actions，也未生成经过原生验收的 macOS／Windows 安装包。

## 下一轮 · 小说可长期使用

- **数据可靠性**：损坏工作区单独恢复、事务日志、备份／迁移／清除凭据、历史容量管理、外部变化提醒。
- **写作结构**：分卷与场景层、排序、重命名作品、可恢复删除、搜索正文和资料、目标字数编辑。
- **长文本**：专业 Markdown 编辑器候选评估，中文 IME、撤销栈、长章渲染和大作品加载性能。
- **AI 深化**：完整 prompt 预览、自动装载 STYLEGUIDE／相关 SOUL、预算、流式、细分模型适配、可编辑提案和差异比较。
- **原生发行**：应用图标、打包 smoke tests、安装卸载、macOS 签名公证、Windows 签名、升级策略。

验收门槛：真实作品持续写作后数据可恢复；macOS 与 Windows 原生 E2E 和人工 IME／窗口／密钥验证通过；不因网络或模型故障中断本地编辑。

## 后续 · 写作框架完整工作流

- **模板与生命周期**：立项简报、设定模板、样章评审、转正与归档、卷和全书阶段门禁。
- **审阅**：Reviewer 证据、多个 Reader 画像、Editor 三段式裁决；严格区分模型建议与作者批准。
- **联动资产**：伏笔账、角色关系、时间线、变更影响与出版准备。
- **版本化**：作品固定框架版本，升级展示变更并迁移；不偷偷追随上游。

验收门槛：同一章从生成、评审到裁决形成可追溯闭环，正文、设定、日志与检查结果一致，阶段回退和停止大修规则可操作。

## 可选模块 · 选择式 IF

场景／选择／条件／类型化变量、剧情子图、路线回放、简单 HTML runtime。世界设定和人物仍引用相同资产 ID；正文与运行状态分离。Twine 的 passage 与 story format 提供参考，而非兼容所有格式的承诺。[Twine 基本概念](https://twinery.org/reference/en/getting-started/basic-concepts.html)

验收门槛：一个包含分支与汇流的短作品独立运行，选择后果和存档可复现，悬空引用和明确不可达节点能被定位。

## 可选模块 · 世界模拟 IF

地点、物件、角色、背包、出口、动作与检查／执行／叙述规则；动作菜单优先，中文／英文有限句型 parser 后接。TADS 世界模型与 Inform 动作处理提供建模依据。[TADS](https://www.tads.org/ov_lib.htm) [Inform](https://ganelson.github.io/inform-website/book/RB_6_2.html)

验收门槛：拿钥匙、开门、探索、对话与结局的完整闭环；缺条件时有正确失败反馈；同一动作无论来自菜单或输入都执行同一逻辑。

## 可选模块 · 视觉小说与发布适配

对白块、背景、立绘、表情、音频、基础转场；先独立浏览器呈现，再生成有限 Ren’Py 子集。其 label、menu、变量与演出语句提供映射参考。[Ren’Py 官方入门](https://www.renpy.org/doc/html/quickstart.html)

验收门槛：导出前报告支持、降级、阻断项；绝不静默忽略世界模拟动作。演出资源版权与实际素材制作单独管理，导出不是自动生成完整 GalGame。

## 明确不启动的工作

账号、远程登录、云端同步、多用户实时协作、社交平台、插件市场和自动公开发布均不在当前路线承诺。只有作者明确提出新的使用场景时才重新评估。
