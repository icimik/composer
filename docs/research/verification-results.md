验证日期：2026-10-09。以下记录区分本轮实际执行、仅配置的自动化和未验证部分，不将开发版当成正式发行版。

## 实际执行环境

- **系统**：Linux 容器，Electron 窗口由 Xvfb 提供图形环境。
- **Node**：22.23.3；初期也在 20.20.2 执行过开发检查，最终使用声明支持的 Node 22 重跑。
- **依赖**：Electron 44.7.0、React 19.3.0、Vite 6.4.4、TypeScript 5.9.3、Playwright 1.64.0，确切版本见 lockfile。
- **数据**：每项测试使用独立临时目录，无真实作者稿件或服务密钥。
- **AI**：本机 mock Chat Completions HTTP 服务，验证真实请求适配、上下文和错误流程，未调用真实付费模型。

## 截图与人工检查

`screenshots/` 保存真实 Electron 内容区截图：明／暗正文、最小窗口、结构总览、阶段检查、模型设置、历史、AI 提案、旧提案错误、200% zoom。截图展示的都是测试文字与 mock 输出。

人工检查发现并修复了暗模式原生控件配色、最小窗口底部换行、短窗口文档树空间、设置错误在 modal 背后不可见、选中态辅助文字两组对比度不足的问题。AI 提案出现后会滚动助手面板到结果，不移动正文。

## 工程限制与依赖告警

完整 `npm audit` 仍报告 8 项 moderate，属于开发／打包依赖链的 `sprintf-js` 及其上游；当前未找到不引入其他兼容风险的已验证修复方案，不隐藏或宣称零风险。该链不在当前 `npm audit --omit=dev` 的生产依赖中；正式发行前需持续检查并复测打包工具。[对应 npm advisory](https://github.com/advisories/GHSA-hp3w-g68c-fv3c)

单文件原子替换不等于跨文件事务；异常断电、损坏工作区隔离恢复、历史容量和大书稿性能还需补充。CI 安装包没有应用定制图标和正式签名，不可宣传为已完成发行。
